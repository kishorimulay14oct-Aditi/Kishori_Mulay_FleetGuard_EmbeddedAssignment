# FleetGuard Intelligent Cold-Chain Monitoring Device

Industrial IoT edge device for monitoring temperature and humidity in refrigerated transport containers.

## Project Status

Initial project setup.

## Project Structure

- `docs/` – Project documentation
- `diagrams/` – System and architecture diagrams
- `firmware/` – Embedded firmware source code
- `hardware/` – Hardware design and BOM
- `reports/` – Engineering report and AI usage report
- `demo/` – Demonstration material
- `assets/` – Project images and screenshots
